# আল-কুরআন — Al-Quran Web App

সম্পূর্ণ কুরআন পড়ার ওয়েব অ্যাপ: আরবি পাঠ, বাংলা অনুবাদ এবং আয়াতভিত্তিক তিলাওয়াত অডিও — সব এক পেজে।

## ফিচারসমূহ

- 📖 **১১৪টি সূরা** — আরবি (উসমানী) পাঠ সহ
- 🇧🇩 **বাংলা অনুবাদ** — মুহিউদ্দীন খান (আয়াতের পাশাপাশি, চালু/বন্ধ করা যায়)
- 🔊 **তিলাওয়াত অডিও** — মিশারী রাশিদ আল-আফাসী; একক আয়াত বা পুরো সূরা একটানা, গতি নিয়ন্ত্রণ (0.75×–1.5×)
- 🌅 **আজকের আয়াত** — প্রতিদিন নতুন একটি আয়াত হোমে
- 🔖 **বুকমার্ক** — যেকোনো আয়াত সংরক্ষণ করুন
- 📍 **শেষ-পড়া মনে রাখে** — যেখানে ছেড়েছিলেন সেখান থেকে চালিয়ে যান
- 🔍 সূরা অনুসন্ধান (বাংলা/ইংরেজি নাম বা নম্বর দিয়ে)
- 🔠 আরবি ফন্টের আকার বড়-ছোট করা, 🌙 ডার্ক মোড
- 📋 আয়াত কপি করা

## ব্যবহার

`index.html` ফাইলটি ব্রাউজারে খুললেই চলবে (ইন্টারনেট সংযোগ লাগবে — পাঠ, অনুবাদ ও অডিও [AlQuran Cloud API](https://alquran.cloud/api) থেকে লাইভ আসে)। GitHub Pages চালু করলে অনলাইনেও ব্যবহার করা যাবে: Settings → Pages → Deploy from branch (main, / root)।

বুকমার্ক ও পড়ার অগ্রগতি ব্রাউজারের localStorage-এ থাকে — কোনো অ্যাকাউন্ট লাগে না।
